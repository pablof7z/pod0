<objective>
Six Rust host crates (`pod0-cli`, `pod0-live-hosts`, `pod0-nostr-host`, `pod0-portable-media`, `pod0-system-hosts`, `pod0-tts-host`) exist on disk but three of them (`pod0-nostr-host`, `pod0-system-hosts`, `pod0-tts-host`) each declare their own `[workspace]` table, which makes each its own workspace root and structurally prevents them from joining `rust/Cargo.toml`'s workspace. This plan removes that mechanism and gets all six crates building, testing, and linting together in the one CI job that already runs `--workspace --all-targets` (`.github/workflows/test.yml` -> `scripts/check_rust.sh`), closing HOST-01 and HOST-02.

Purpose: without this, no other Phase 1 work (runtime consolidation, HTTP client dedup, approval parity) is even reachable by the workspace-wide build the CI job runs — this is the tracer that proves the six-crate integration compiles as one unit before anything inside those crates is touched.
Output: a 13-member `rust/Cargo.toml` workspace, three crate manifests with their `[workspace]` stanza removed, two reconciled duplicate-version dependency pins, and a green `cargo build/test/clippy --workspace --all-targets` run.
</objective>

Delete the trailing `[workspace]` table (a bare `resolver`-less `[workspace]` line with no members — this is what makes each crate its own workspace root) from `rust/crates/pod0-nostr-host/Cargo.toml` (line 26), `rust/crates/pod0-system-hosts/Cargo.toml` (line 39, keep the "deliberately self-contained" comment removed too since it's now stale), and `rust/crates/pod0-tts-host/Cargo.toml` (line 28, same comment removal). After both manifest edits, regenerate `rust/Cargo.lock` by running a workspace build (this pulls the three newly-joined crates' full dependency trees into the lockfile for the first time — expect a large diff; that is expected, not a mistake).
